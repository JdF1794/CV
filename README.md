# Personal Website Deployment Instructions

## Customizing Your Website
1. **Clone the Repository**: Run the following command to clone the repository to your local machine:
   ```bash
   git clone https://github.com/JdF1794/CV.git
   ```

2. **Customize the Content**: Open the files in a text editor and customize the content as needed. The main files to edit are:
   - `index.html`: The main page of your personal website.
   - `styles.css`: The stylesheet for your website.
   - Additional sections can be added in separate HTML files.

## Deploying Your Website

### Enable GitHub Pages
1. **Go to Your Repository Settings**: Navigate to the `Settings` tab of your repository.
2. **Locate the GitHub Pages Section**: Scroll down to the `GitHub Pages` section.
3. **Select the Source**: Under `Source`, select the `main` branch as your source for GitHub Pages.
4. **Save**: Click `Save` to enable GitHub Pages.
5. **Access Your Website**: After a few minutes, your website will be available at `https://jdF1794.github.io/CV/`.

## Additional Information
- Make sure to push your changes to GitHub to see the updates on your deployed site.
- You can manage branches using Git for advanced deployment or testing.

Happy coding!
